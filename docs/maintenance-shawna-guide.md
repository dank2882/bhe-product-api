# Maintenance — Shawna’s Quick Guide

Updated September 23, 2026 • Faith Baptist Church

## Open the system
Use your own ChatGPT account and select **FBC Staff Tools Production v2**.
“Show the Maintenance board.”
To retrieve this sheet:
“Open the Maintenance project and show Shawna’s Quick Guide from its project notes.”

Tell chat what to change. The table is a retrieved view; refresh it after a saved change.

## What needs approval?
Incoming emails and texts enter the Maintenance inbox. They do not automatically create tasks, change work, or mark repairs complete. Review the request, check for an existing task, then approve the appropriate task change and linking of its original message/photos.

A task you explicitly create in chat goes onto the Maintenance list without a second approval step. Existing tasks do not need approval again simply to remain on the list.

These are separate decisions:
- Approve adding or updating the maintenance work.
- Approve a sender/recipient and record their actual permission to receive messages.
- Approve the exact outgoing email before sending.

Assigning a task does not automatically email the worker. A contractor saying “done” does not automatically complete the task.

## 1. Review the inbox
People email **maintenance@foundedonfaith.com** with the building, exact location, problem and photo. Email pickup normally runs about every five minutes.

“Show the Maintenance inbox, including requests waiting for review and quarantined senders. Show sender, subject, date, photo status and review status. Tell me if more pages are available.”

“Open the request titled [subject] from [sender]. Show the original message, check its photos, and suggest an existing task match or a new task. Do not save changes yet.”

Check the location, work description and proposed match. Unknown senders may be quarantined for manager review. Do not guess an unclear building or task match.

## 2. Add or link an approved request
For a new task:
“Create a Maintenance task from this request in [building / location], titled [repair name], with priority [priority]. Link the original request and its photos.”

For an existing task:
“Link this request and its photos to [M-reference]. Add this note: [your update].”

Supply a deadline only when there is a real one. Keep estimated and actual costs separate.

Verify:
“Show the saved task and open its photo viewer. Confirm the original inbox request is linked to this task.”

A linked request remains in inbox history with its review status; it does not need to disappear.
For unwanted or duplicate requests:
“Dismiss this inbox request; do not create another task.”

If photos are still processing, wait and check again. For failed photos, ask chat to show the failure and retry photo processing. Confirm which photos were actually linked.

## 3. Work with the board
- “Show Maintenance tasks for B Building.”
- “Show unassigned Maintenance tasks.”
- “Open [M-reference] and show its full notes.”
- “Change the priority of [M-reference] to high.”
- “Add this note to [M-reference]: [exact update].”
- “Assign [M-reference] to [name].”
- “Mark [M-reference] complete. Completion note: [what was done].”

Use the task name or M-reference, not its row number. Ask for clarification if a match is uncertain. Staff assignments may require the assignee’s acceptance; proposed does not mean accepted. Ask to see the saved task after changes.

## 4. View photos
“Open the Maintenance photo viewer for [M-reference].”
Select a thumbnail to enlarge it. Refresh renews expired private links.
Download original provides the full image; ChatGPT may ask you to confirm opening the link.
The Images column shows the photo count. A source note mentioning a photo is not proof that a photo is attached.
An older cached viewer may show an unnecessary Next button for a one-photo task.

## 5. Email a worker or contractor
Maintenance emails send from **maintenance@foundedonfaith.com** through FBC Staff Tools. You do not need another person’s Outlook account for this workflow.

Confirm the recipient’s exact address. They must be approved and have actual permission to receive Maintenance messages documented. Approval to submit requests is separate from permission to receive outgoing messages.

“Show the Maintenance reporter record for [email]. Is this person approved, and is permission to receive Maintenance emails documented?”

If setup is needed, supply the person’s name, exact address and real consent details. Never invent consent.

Draft:
“Draft a Maintenance email to [exact email address] about task [M-reference]. Include the building, location, requested work and [agreed deadline, if any]. Include [specific intake photos, if wanted]. Show the recipient, subject, full wording and selected photos before sending.”

Review everything and request corrections if needed. A changed draft needs fresh approval.
Send only when correct:
“I approve sending this exact draft to [email address] with the listed photos.”

Then:
“Check the outgoing email’s status and show its receipt.”

One recipient is supported per draft; use separate approved drafts for different recipients.
Up to five processed inbox photos may be attached, within the total attachment-size limit. Ask chat to confirm the selected photos are available. Other task attachments are not automatically email attachments.
Email sending is enabled. Outgoing text messages are not yet enabled.
“Accepted” means the provider accepted the email, not that delivery was confirmed. If status is sending or unknown, check status rather than sending again.

## 6. Recurring duties and archived work
“Show Maintenance recurring duties.”
“Record that [routine] was completed on [date], with this note: [details].”
Record an occurrence; do not end the entire recurring duty after one completion.

“Archive Maintenance task [M-reference].”
“Show archived Maintenance tasks.”
“Restore [M-reference] to the active list.”

Archiving hides work from normal lists and can be reversed. It is different from marking work complete. Shared staff can archive and restore; permanent deletion is not part of this workflow.

## Daily routine
1. Review new inbox requests.
2. Check board priorities, assignments and waiting items.
3. Send only emails you reviewed and explicitly approved.
4. Record updates and completed recurring occurrences.
5. Confirm saved changes and check uncertain email status.

For a problem, note the task reference or subject, what you asked, and the exact error. Ask Dan for help with access or system setup.
