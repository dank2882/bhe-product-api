# Philippines Missions Trip Website Artwork

These source assets were prepared for the August 2-11, 2026 Philippines
missions trip website. They are retained here as versioned artwork; their
presence in Git does not indicate that a Wix draft was approved or published.

- `philippines-trip-home-carousel-v1.jpg` - 2000 x 400 compressed delivery
